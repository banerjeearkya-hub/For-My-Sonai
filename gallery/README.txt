=======================================================
❤️ HOW TO ADD YOUR OWN PHOTOS FOR NASRIN
=======================================================

1. Copy your photos into this folder:
   c:\Users\Arkya\OneDrive\Desktop\MAgra mariners\public\gallery\

   Example:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg

2. Open `src/data/loveContent.ts`

3. Update the `gallery.items` array:
   {
     id: "photo-1",
     title: "Our Date Night",
     caption: "Your smile was brighter than all the city lights.",
     date: "October 2026",
     image: "/gallery/photo1.jpg",
     tilt: -1.5
   }

4. Save `loveContent.ts`. The website will instantly display your real photo!
